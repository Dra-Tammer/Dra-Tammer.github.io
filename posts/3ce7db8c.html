Basic Concepts

state

agent相对于环境的状态

state space就是一个集合

action

For each state, the agent can take several possible actions.

action space也是一个集合

action space和状态是依赖的，其是S的函数；不同状态的action space不一样

state transition

表格表示状态转移只能表示确定性的情况

可以通过conditional probability（条件概率）去表示状态转移

policy

A policy tells the agent which actions to take at every state.

policy采取一系列的action

用矩阵表示一个策略就是tabular的方法

reward

数，一个标量

A reward can be interpreted as a human-machine interface.

trajectories, returns and episodes

A trajectory is a state-action-reward chain. The return of this trajectory is defined as the sum of all the rewards collected along the trajectory.

return能够评价一个策略是好是坏。引入discount rate（折扣因子），得到discounted return，通过控制折扣因子γ，控制agent所学到的策略，γ越小越近视，γ越大越远视。

An episode is usually assumed to be a finite trajectory. It is a trial.

episode是有限步的，永远持续的是continuing tasks.

Markov decision processes (MDP)

The key ingredients of an MDP are listed below.

  • Sets:
    • state space
    • action space
    • reward set
  • Model:
    • state transition probability
    • reward probability
  • Policy
  • Markov property: 和历史无关

什么是马尔可夫过程

Markov: Markov property (meaningless property)

decision: policy

processes: sets+model

State Values and Bellman Equation

return能够评估一个策略的好坏

How to calculate returns

  • by definition
  • bootstrapping

bootstrapping: 从不同状态出发得到的return依赖于从其他状态出发得到的return

state value

可反映一个状态的价值，也能反映一个策略的好坏

state value就是在某个固定策略下的状态价值

$$
vπ(s) = E[Gt |St = s].
$$
多步平均值：state value，单步平均值：return

The relationship between state values and returns is further clarified as follows. When both the policy and the system model are deterministic, starting from a state always leads to the same trajectory. In this case, the return obtained starting from a state is equal to the value of that state. By contrast, when either the policy or the system model is stochastic, starting from the same state may generate different trajectories. In this case, the returns of different trajectories are different, and the state value is the mean of these returns.

Bellman Equation

$$
v = r + γPv.
$$

描述了不同状态的state-value之间的关系，可以使用iteration solution进行计算。

action value

state value: the average return the agent can get starting from a state

action value: the average return the agent can get starting from a state and take an action

state value是按策略对action value的加权平均，对于一个状态所有的action value求一个加权平均就是state value。

action value和reward的异同点和联系

reward是执行动作后，环境立即给予agent的反馈。而action value是agent在状态s执行a，然后按照策略π行动，未来总回报的期望。

action value = reward + future reward

Optimal State Values and Bellman Optimality Equation

强化学习的最终目的：寻找最优策略

Use action value to get a better policy

We can obtain a better policy if we update the policy to select the action with the greatest action value.

对每一个状态都选择action value最大的那个action，不断迭代，最后的策略趋向于一个最优策略。

optimal policy and optimal state value

A policy π ∗ is optimal if vπ∗ (s) ≥ vπ(s) for all s ∈ S and for any other policy π. The state values of π ∗ are the optimal state values.

bellman optimality equation

贝尔曼最优公式（BOE）是分析最优策略和最优state value的工具。

贝尔曼公式一定是对应一个π∗，v∗是π∗所对应的state value

最优策略的影响因子

reward, model, discount rate

What matters most is not the absolute reward values! It’s their relative value.

有discount rate的存在能够防止agent绕远路。

对于BOE，其optimal state value是唯一的，但是对应optimal state value的最优策略不一定唯一。

Value Iteration and Policy Iteration

model-based: 已知MDP，也是已知环境，find optimal policy.

value iteration

  1. policy update
  2. value update

matrix vector form一般用于做理论分析，而elementwise form一般用于代码实现

policy iteration

  1. policy evaluation: 任意给一个policy，求出state value
  2. policy improvement

在证明策略迭代收敛的时候用到了值迭代算法是收敛的这样一个结果。

策略迭代和值迭代是truncated policy iteration的两个极端。策略迭代理论上来说要计算无穷多步，truncated policy iteration计算有限步。

接近目标的状态策略会先变好。

summary

值迭代是直接求解BOE，策略迭代是通过交替使用Bellman方程和策略改进，简介求解BOE。
