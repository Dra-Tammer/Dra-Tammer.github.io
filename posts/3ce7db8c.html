Basic Concepts

state

agent相对于环境的状态

state space就是一个集合

action

For each state, the agent can take several possible actions.

action space也是一个集合

action space和状态是依赖的，其是S的函数；不同状态的action space不一样

state transition

表格表示状态转移只能表示确定性的情况

可以通过conditional probability（条件概率）去表示状态转移

policy

A policy tells the agent which actions to take at every state.

policy采取一系列的action

用矩阵表示一个策略就是tabular的方法

reward

数，一个标量

A reward can be interpreted as a human-machine interface.

trajectories, returns and episodes

A trajectory is a state-action-reward chain. The return of this trajectory is defined as the sum of all the rewards collected along the trajectory.

return能够评价一个策略是好是坏。引入discount rate（折扣因子），得到discounted return，通过控制折扣因子γ，控制agent所学到的策略，γ越小越近视，γ越大越远视。

An episode is usually assumed to be a finite trajectory. It is a trial.

episode是有限步的，永远持续的是continuing tasks.

Markov decision processes (MDP)

The key ingredients of an MDP are listed below.

  • Sets:
    • state space
    • action space
    • reward set
  • Model:
    • state transition probability
    • reward probability
  • Policy
  • Markov property: 和历史无关

什么是马尔可夫过程

Markov: Markov property (meaningless property)

decision: policy

processes: sets+model

State Values and Bellman Equation

return能够评估一个策略的好坏

How to calculate returns

  • by definition
  • bootstrapping

bootstrapping: 从不同状态出发得到的return依赖于从其他状态出发得到的return

state value

可反映一个状态的价值，也能反映一个策略的好坏

state value就是在某个固定策略下的状态价值

$$
vπ(s) = E[Gt |St = s].
$$
多步平均值：state value，单步平均值：return

The relationship between state values and returns is further clarified as follows. When both the policy and the system model are deterministic, starting from a state always leads to the same trajectory. In this case, the return obtained starting from a state is equal to the value of that state. By contrast, when either the policy or the system model is stochastic, starting from the same state may generate different trajectories. In this case, the returns of different trajectories are different, and the state value is the mean of these returns.

Bellman Equation

$$
v = r + γPv.
$$

描述了不同状态的state-value之间的关系，可以使用iteration solution进行计算。

action value

state value: the average return the agent can get starting from a state

action value: the average return the agent can get starting from a state and take an action

state value是按策略对action value的加权平均，对于一个状态所有的action value求一个加权平均就是state value。

action value和reward的异同点和联系

reward是执行动作后，环境立即给予agent的反馈。而action value是agent在状态s执行a，然后按照策略π行动，未来总回报的期望。

action value = reward + future reward

Optimal State Values and Bellman Optimality Equation

强化学习的最终目的：寻找最优策略

Use action value to get a better policy

We can obtain a better policy if we update the policy to select the action with the greatest action value.

对每一个状态都选择action value最大的那个action，不断迭代，最后的策略趋向于一个最优策略。

optimal policy and optimal state value

A policy π ∗ is optimal if vπ∗ (s) ≥ vπ(s) for all s ∈ S and for any other policy π. The state values of π ∗ are the optimal state values.

bellman optimality equation

贝尔曼最优公式（BOE）是分析最优策略和最优state value的工具。

贝尔曼公式一定是对应一个π∗，v∗是π∗所对应的state value

最优策略的影响因子

reward, model, discount rate

What matters most is not the absolute reward values! It’s their relative value.

有discount rate的存在能够防止agent绕远路。

对于BOE，其optimal state value是唯一的，但是对应optimal state value的最优策略不一定唯一。

Value Iteration and Policy Iteration

model-based: 已知MDP，也是已知环境，find optimal policy.

value iteration

  1. policy update
  2. value update

matrix vector form一般用于做理论分析，而elementwise form一般用于代码实现

policy iteration

  1. policy evaluation: 任意给一个policy，求出state value
  2. policy improvement

在证明策略迭代收敛的时候用到了值迭代算法是收敛的这样一个结果。

策略迭代和值迭代是truncated policy iteration的两个极端。策略迭代理论上来说要计算无穷多步，truncated policy iteration计算有限步。

接近目标的状态策略会先变好。

summary

值迭代是直接求解BOE，策略迭代是通过交替使用Bellman方程和策略改进，简介求解BOE。

Monte Carlo Methods

model-free

通过大量采样的真实回报来估计价值函数

用数据估计出来一个模型，基于这个模型进行强化学习

model-based reinforcement learning (MBRL)

更准确的方法：dynamic programming动态规划的方法

大量采样，然后实验，最后用实验结果来近似，都可以称之为MC的方法

When model is unvailable, we can use data(sample, experience< in RL >)

当没有模型（概率分布），得有数据，没有数据的时候得有模型

MC与policy iteration的异同

都是两步

  1. policy evaluation
  2. policy improvement

只不过在第一步有点区别，MC是直接估计出来action value，而策略迭代是state value转成action value

MC: 生成episode -> 计算return -> 估计Q(s, a) -> greedy改进policy

MC Exploring Starts

普通的MC方法，一直greedy下去，很多(S, A)永远访问不到，缺乏探索性

解决如何充分探索的问题，同时解决样本利用。理论能够保证收敛到最优解，但是过于理论，实用性极低。

从每个(s, a)开始的episode，每个(s, a)都能被访问到

让策略本身具有探索能力

$$
MC \epsilon-greedy
$$

平衡exploitation和exploration

$$
\epsilon越大，探索性越强
$$
$$
以概率\epsilon随机选择动作（探索），以1-\epsilon选择当前Q值最高的动作（利用）

  • incremental: 每生成一个sample，就更新value

off-policy VS on-policy

Two policies exist in any reinforcement learning task: a behavior policy and a target policy. The behavior policy is the one used to generate experience samples. The target policy is the one that is constantly updated to converge to an optimal policy. When the behavior policy is the same as the target policy, such a learning process is called on-policy. Otherwise, when they are different, the learning process is called off-policy. The advantage of off-policy learning is that it can learn optimal policies based on the experience samples generated by other policies, which may be, for example, a policy executed by a human operator.

on-policy

behavior policy与target policy相同，利用这个policy与environment交互得到的experience同时再改进这个policy

Q-learning is off-policy

eg: agent实际用了e-greedy探索，但是更新时仍然使用了maxQ

Value Function Methods

之前的情况都是tabular的方法，使用表格直接存储每个状态或者状态-动作对的价值。这个方法无法应对状态空间过大，故用函数逼近的方法。同时value function的方法具有更强的泛化能力。

泛化能力：不需要把所有状态空间全都访问到，访问其中的一些相邻的值会比较准确被估计出来。

From table to function

用曲线去拟合Vpi(s), 泛化能力更强，存储权重w就行，节省存储。或者用更高阶的曲线去拟合。

这时候就需要用神经网络去逼近，神经网络理论上来说，可近似任何一个非线性函数

Deep Q-learning

function：估计optimal action value

训练的关键技巧

  1. 两个网络：main network和target network，在训练中main network的w一直在更新，隔段时间将main network的w赋值给target network。online network用于训练，target network用于计算target。
  2. 经验回放（experience replay）：将experience sample存储在replay buffer中，之后更新参数权重的时候考虑之前的经验。

Policy Gradient Methods

策略梯度

tabular的方法：每个单元格代表某一个状态下take某个action的概率是多少

之前使用表格表示policy，进化为用函数表达

直接建立一个目标函数，关于policy的objective function，优化这个function就得到了optimal policy。

  • First, how to define optimal policies? When represented as a table, a policy is defined as optimal if it can maximize every state value. When represented by a function, a policy is defined as optimal if it can maximize certain scalar metrics.
  • Second, how to update a policy? When represented by a table, a policy can be updated by directly changing the entries in the table. When represented by a parameterized function, a policy can no longer be updated in this way. Instead, it can only be updated by changing the parameter θ.
  • Third, how to retrieve the probability of an action? In the tabular case, the probability of an action can be directly obtained by looking up the corresponding entry in the table. In the case of function representation, we need to input (s, a) into the function to calculate its probability. Depending on the structure of the function, we can also input a state and then output the probabilities of all actions.

Some remarks

这两个公式在相关的论文中很常见

All these metrics are functions of π. Since π is parameterized by θ, these metrics are functions of θ. In other words, different values of θ can generate different metric values. Therefore, we can search for the optimal values of θ to maximize these metrics. This is the basic idea of policy gradient methods.

The two metrics ¯vπ and ¯rπ are equivalent in the discounted case where γ < 1. In particular, it can be shown that
$$
r_π = (1 − γ)¯v_π.
$$
The above equation indicates that these two metrics can be simultaneously maximized.

Gradients of the metrics

¯vπ and ¯rπ等价：对一个作优化另一个也达到极值

$$
\nabla_{\theta} J(\theta)=\mathbb{E}{S \sim \eta, A \sim \pi(S, \theta)}\left[\nabla{\theta} \ln \pi(A \mid S, \theta) q_{\pi}(S, A)\right]
$$

这是一个真实的梯度，用采样去进行近似

Actor-Critic Methods

Here, an “actor” refers to a policy update step. The reason that it is called an actor is that the actions are taken by following the policy. Here, an “critic” refers to a value update step. It is called a critic because it criticizes the actor by evaluating its corresponding values. From another point of view, actor-critic methods are still policy gradient algorithms.

QAC

Actor: 更新策略

Critic: 对当前的策略进行评估，估计计算出对应的action-value

引入b不发生变化，成立（不影响梯度）

降低采样方差，越接近真实E
