# 足迹地图

原生 Canvas 2D 和 JavaScript 实现，页面所需资源都随博客本地部署，不加载在线地图服务或第三方地图运行库。

## 地图与交互

- 默认只显示省级边界；放大至初始视图的 1.8 倍（增加 80%）时显示市级边界，缩小到阈值以下恢复省界。直辖市和香港、澳门在详细层使用区级边界。阈值由 `map.js` 的 `CITY_DETAIL_ZOOM` 控制。
- 按鼠标所在位置进行滚轮缩放，范围 0.75–24 倍；也支持加减按钮和拖动。
- 概览层高亮到访省级地区，详细层按到访城市填色；命中检测跟随可见边界切换。
- 悬停或点击区域时显示地名；左上角仅保留“城市 · 省区”统计，不显示标题、说明和图例。城市数沿用足迹记录数，省区数按省级行政区划代码去重。
- 仅保留放大、缩小按钮；城市列表与重置按钮已移除。
- 只在交互、窗口尺寸变化时重绘，静止时不运行绘制循环；屏幕之外的区域跳过绘制。

## 维护足迹

编辑 `cities.js`：

```js
[纬度, 经度, '地点名称', '省级地区', 所属城市行政区划代码]
```

例如都江堰属于成都市，填写 `510100`；凤阳属于滁州市，填写 `341100`。北京、上海、香港等使用省级代码，其下属区会一同着色。足迹点独立保留原经纬度。

## 文件

- `index.html`：页面结构。
- `map.css`：简化后的地图和控件样式。
- `map.js`：坐标投影、GeoJSON 路径、绘制、区域命中和交互。
- `cities.js`：足迹数据。
- `map-data.js`：本地保存的地理边界。

## 边界来源与更新

来源：[阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)。2026-10-23 获取全国省级数据 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json` 及各省的 `{省级代码}_full.json`，保留 Polygon/MultiPolygon 的所有外环、内环与岛屿，坐标保留五位小数。

当前包含 34 个省级地区、475 个市/区级区域，另保留数据源提供的海域线要素。普通省份是地级市、自治州等层级，直辖市及港澳细化到区。数据源未提供台湾下级城市轮廓，因此台湾显示省级轮廓，不捏造边界。行政区划采用源数据版本，不保证与当前调整完全同步。初始视图聚焦主要陆地区域，南部海域要素保留在数据中，可缩小和拖动查看。

地图边界属于外部地理数据，绘制和交互代码自行实现。使用数据应遵循提供方的使用要求；此页面用于个人足迹展示。

手动重新获取静态数据（正常 Hexo 构建不联网获取）：

```sh
node tools/build-footprint-data.cjs
```

本地预览：

```sh
npm run build
npm run server
```

打开 `/about/` 查看嵌入效果，或 `/footprints/` 单独查看。
